# Cloudflare DDNS

Home Assistant App baseado no projeto `timothymiller/cloudflare-ddns`.

Configuração predefinida:
- `app.xavelha.top` → DNS Only
- `micro.xavelha.top` → Proxied
- `canico.xavelha.top` → Proxied
- IPv4 via Cloudflare Trace
- IPv6 desativado
- Verificação a cada 5 minutos

O API Token é introduzido na configuração do Home Assistant e não deve ser colocado no GitHub.
