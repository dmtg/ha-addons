# Cloudflare DDNS

Home Assistant App para atualizar automaticamente registos DNS da Cloudflare.

Configuração predefinida:
- app.xavelha.top: DNS Only
- micro.xavelha.top: Proxied
- canico.xavelha.top: Proxied
- IPv6 desativado
- Atualização a cada 5 minutos

O API Token é configurado na interface do Home Assistant e não deve ser colocado no GitHub.
